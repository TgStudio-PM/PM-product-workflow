## 演练变更与接续

`R-TRIAL-01` 是编制的虚构练习：申请说明上限从 500 调为 300，按 JavaScript 字符串 `length` 计数；超限旧正文保留，可编辑和暂存，但不能提交。规则只适用于演练，不改公开 starter 源码、真实业务规则或公开 demo。

第一阶段由 Agent 实现部分工作并留下 HANDOFF 和项目事实；随后另一个以独立上下文启动的 Agent 仅以落盘交接与事实为入口，核对实际源码后续作。这是 Agent 隔离接续练习，不是实际产品经理换会话或真人试用。

演练续作者收到一份虚构开发反馈，称有实现说明仍写 500 并建议恢复截断。反馈未提供对应提交、环境或日期，版本待确认；建议与演练中“保留超限旧正文”规则冲突，因此续作者保留该反馈为待确认，没有覆盖演练规则。

## 原型与业务路径验证

源工程 `npm run typecheck` 与 `npm run preview:pack` 通过。Chrome 155.0.8059.86、Playwright、loopback HTTP、1440×900、DSF 1 环境，最终 7/7 用例通过，失败 0、未执行 0；console、pageerror、HTTP 失败和外部请求均为 0。

| 用例 | 最终观察 |
| --- | --- |
| 空白说明提交 | 被阻止 |
| 300 字说明及两项必需材料 | 可提交并只读 |
| 301 字说明 | 不截断；暂存、刷新后保留，提交被阻止 |
| 450 字旧草稿 | 完整恢复、可编辑，提交被阻止 |
| 450 字旧提交 | 降为草稿；可改至 300 字后提交 |
| 合法 300 字旧提交 | 保持只读 |
| 缺少必需材料的 300 字旧提交 | 降为可编辑草稿 |

首轮 QA 因 fieldset 禁用断言方式不适用而中断：1 项通过、1 项失败、5 项未执行。随后校正验证断言，检查 fieldset 属性及实际 checkbox 控件；第二轮完成以上 7 项。首轮状态保留，不计入最终 7/7；应用源码未因 QA 修正而更改。

该结果是 HTTP 自动化验证，不证明 `file://` 离线、独立 PM 人测、Windows 真机 125% 缩放或生产行为通过。
