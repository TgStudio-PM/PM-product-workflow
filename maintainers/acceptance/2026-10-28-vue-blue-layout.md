# Tg Studio Vue starter：政务蓝与可读性复验

- 日期：2026-10-28
- 范围：Issue #134；共享视觉样式、starter 使用说明和开发入口图标
- 分类：用户设计偏好调整，不是平台规范合规结论

## 调整与结果

按用户偏好将青绿色主色改为政务蓝，并提高常用文字、导航和控件尺寸。调整后的主色为 `#1d63b8`；常用字 14px、辅助字不小于 12px、导航 15px、控件高度 40px；布局最大宽度 1920px，并按 1100/850/620px 断点调整。

Browser plugin not available：本次使用已有 Playwright，以 Chrome 155.0.8059.86 对本地 HTTP 预览进行自动化复验。2048×1050、设备像素比 1.25 的密度模拟下，内容宽度从 1280px 增至 1920px；表格字号从 10px 增至 14px，输入字号从 12px 增至 14px。1280×800 下两页均保留主副栏双列；1000×800 下改为单列；390×844 下单列且内容宽度适配视口。四种视口均无文档横向溢出。

主要交互检查通过：查询筛选与重置、选择记录查看详情、虚构草稿保存并刷新恢复、清除确认弹窗显示及取消。初次发现的 favicon 404 已修复；新 Chrome 上下文定向复验中，页面错误、控制台错误、失败请求及 HTTP 4xx/5xx 均为 0。`npm run preview:pack` 的类型检查、构建和独立验包通过。

## 验收边界

2048×1050 的设备像素比为自动化密度模拟，不是 Windows 真机 2K、125% 缩放验收。未验证 Edge、新样式的 `file://` 预览或零网络离线运行；本次使用本地 HTTP 预览，存在正常同源请求。Issue #75 旧版绿色包的 Chrome、Edge `file://` 结果不代表本次新样式。原生案例第四轮、独立人测及正式 Release 仍需分别验收。
