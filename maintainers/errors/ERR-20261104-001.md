# ERR-20261104-001：项目级入口摘要滞后于模块验收记录

- 状态：已解决（仅项目文档同步）
- 日期：2026-11-04
- 范围：[Issue #179](https://github.com/TgStudio-PM/PM-product-workflow/issues/179)；项目背景、模块清单及中英 README 的验收摘要

## 现象与复现

项目背景和模块清单仍称最新 `file://` 验收待执行，中英 README 也未区分已有定向证据与后续变更的验证范围。最小复现是对照四份项目入口文档与模块 `CURRENT.md`、`ITERATIONS.md` 及其引用的验收记录：模块已有 Issue #168 修复后 Chrome 155/Edge 156 的原生案例 `file://` 定向流程记录；README 所述 PR141 本地 HTTP 及 PR175 最新首页候选的验证范围则各有边界。

## 影响与根因

接续者可能误以为原生案例从未有修复后 `file://` 验收，或把定向 case、历史完整矩阵与较新的 HTTP 首页复核混为一谈。根因是模块事实更新后，项目入口摘要没有同步。本问题是项目级状态滞后，不同于 [ERR-20261029-002](ERR-20261029-002.md) 的规则编号与引用遗漏。

## 修正与验证

项目背景改为概述第四轮状态，并链接模块 `CURRENT.md`；模块清单同步状态和核对日期，同样指向该权威正文。中英 README 同步说明 Issue #168 的定向 `file://` 记录及其范围、后续路径/首页变更的独立记录，以及最新首页候选只有 HTTP 复核且 `file://` 导航受阻。独立非开发 PM 人测、手工双击和 Windows 真机 2K/125% 仍标为未完成。范围外项明确指生产交付与真实办理，不否认教学静态包。

本次仅同步文本和现有链接；未新增或运行浏览器、产品或模块测试。Markdown 链接、公开内容扫描和 `git diff --check` 结果在本次变更后记录；CI 以最终 PR 提交为准。
