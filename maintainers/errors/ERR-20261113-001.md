# ERR-20261113-001：UI Skill 独立复制后引用仓库外资源

- 日期：2026-11-13
- 状态：已解决（限独立分发引用及离线源码任务复核）
- 范围：[Issue #208](https://github.com/TgStudio-PM/PM-product-workflow/issues/208)，两个 UI Skill 的分发方式与使用说明

## 现象与影响

按使用指南把 `gov-ui-reviewer`、`gov-ui-refactor` 完整目录分别复制到独立 Skills 根目录，前者的两个 Profile/模板相对链接、后者的一个 Profile 相对链接均指向不存在的文件。保留工作流仓库布局时可访问，单目录分发时不能按原链接读取。

这会使使用者额外恢复仓库布局，或使执行者无法区分“已读取默认预设”与“仅依据项目规范”。根因已定位：资源实际维护在仓库根 `profiles/`，相对链接却假设安装后仍保留该布局；Skill 目录没有包含这些资源。

## 修正

保留唯一 Profile 正文，两个 Skill 优先使用项目提供的规范/Profile 路径，默认预设和模板改用可选公共链接。独立复制不要求恢复整仓布局；离线或无法获取默认预设时说明未检查范围，继续有明确项目依据的任务，不声称读取未取得的资源。

不增加安装器、不复制规范正文、不改变本机安装，也不改变只读评审、定向改造或业务验收边界。

## 验证与预防

原始独立复制记录保存在本机。修正副本的相对资源缺失为零；默认公共链接指向基线仓库中实际存在的规范正文和模板。

独立执行者仅访问复制的 Skill 目录、Vue 页面及本地项目设计 V2，不联网或读取原仓库。已完成一次只读评审和一次明确颜色修改；两份结果均说明未取得默认预设，没有作平台合规判定，也没有因缺少预设停止明确任务。主线核对七份受保护输入哈希不变，第八份页面字节仅替换一次目标色值，保留 Vue、Element Plus、原事件和用户备注。

两个 Skill 元数据、16 项治理测试、Markdown 链接及公开内容检查通过；最终 CI 以对应 PR 记录为准。此复核没有运行 Vue 构建或浏览器，不作为页面运行验收或独立产品经理完整试用。

分发文档中的“复制完整 Skill 目录”不能隐含依赖目录之外的文件；可选参考应有明确来源与缺失处理方式。格式与链接通过不等于离线行为已验证。

## 同类引用补查

四个核心 Skill 独立复制后，记忆与接续没有外部文件引用，需求写作的参考仍在自身目录内。打包器使用已有 Profile 时已能独立构建和验包，但可选指南仍为断开的仓库相对链接，命中了同类资源引用问题。

在 [Issue #210](https://github.com/TgStudio-PM/PM-product-workflow/issues/210) 下重开并修正该剩余引用：指南和模板使用可选公共链接，命令示例以所选 Skill 目录为基准。没有修改打包脚本或格式。原独立副本的构建与独立验包均 exit 0，脚本与基线一致；修正后的参考链接复核不再缺失，重新关闭范围限本次资源与调用说明，不代表所有交付类型已在新环境验收。
