# ERR-20261024-006：离线页面清单未转义表格单元格

- 状态：已解决
- 日期：2026-10-24
- 范围：Tg Studio Vue 原型工程的离线页面清单构建和验包；Issue #87

## 现象与复现

在公开 Vue starter 的隔离副本中，将虚构页面标题设为 `演示 | 帮助`，运行 `npm run preview:pack`。构建和验包均返回成功，但 `PAGES.md` 生成 `| /demo-help/guide | 演示 | 帮助 |`，Markdown 表格列数失真。未运行或打开真实项目，未影响 Vue 应用运行。

错误特征：页面标题或路由含 `|`、换行、HTML 或 Markdown 控制字符时，构建与验包以相同的未转义字符串生成并核对清单；两者一致仍可能接受无效表格。

## 影响与根因

接收离线包的人可能从 `PAGES.md` 读到错误的页面列或显示结构。根因是将静态页面路由与标题直接插入 Markdown 表格，没有对单元格中的管道符、内联格式标记、HTML 控制字符和换行做表示层转义；构建与验包重复相同假设。

## 尝试及结果

- 在隔离虚构副本以管道符标题复现，并确认构建和验包都误报成功。
- 新增独立回归时，首次运行发现换行转换后的 `<br>` 又被后续 HTML 转义编码；调整为一次扫描并在该测试通过。
- 在专用隔离集成测试中使用含 `|`、CRLF、HTML 和 Markdown 控制符的虚构标题，检查确切 `PAGES.md` 输出和 manifest 中原始值；另修改清单并更新其 SHA-256，确认验包仍因内容不一致拒绝。

## 最终修复、验证与预防

共享页面注册表模块现在格式化完整页面清单，将表格分隔符、HTML 字符及 Markdown 内联语法字符编码为实体，将换行转成 `<br>`；构建和验包共用此格式，`manifest.json` 仍保存原始路由和标题。普通标题保持原输出。Vue starter README 已说明含特殊字符的旧包须重新生成。

定向验证结果以 Issue #87 关联 PR 为准。本地相关预览测试、类型检查、构建和验包均通过；浏览器 `file://` 和非开发产品经理人测未执行。含特殊字符且按旧规则生成的包若需新版验包通过，须运行 `npm run preview:pack` 重新生成。

预防规则：构建和验包共享规范输出时，测试必须独立断言规范输出本身，并加入重算校验摘要后的篡改负例，避免仅通过双方使用同一错误格式互相验证。

证据：Issue #87、`starters/vue-prototype/tests/verify-preview.test.mjs` 隔离构建/验包回归。
