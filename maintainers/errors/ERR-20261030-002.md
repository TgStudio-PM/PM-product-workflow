# ERR-20261030-002：Vue 离线预览未保留完整运行许可正文

- 状态：已解决（本记录覆盖的 Vue 固定运行组件与本地预览包范围）

- 范围：[Issue #164](https://github.com/TgStudio-PM/PM-product-workflow/issues/164)，`starters/vue-prototype` 本地预览生成、验包及相关交接说明

## 现象与证据

原 Vue 静态预览归档 `vue-static-preview-baseline_057f395_20261029.zip`（SHA256 `78a38ec97bfc7ab4849093a338272c252fbf354b68b1502d6b7d7b075a3b1b0b`）仅含 7 项，`app.js` 有 Vue 子包版权归属与 `@license MIT` 注释，但包内没有完整许可正文，也没有 `LICENSE` 文件。已安装的 `vue`、`@vue/shared`、`@vue/reactivity`、`@vue/runtime-core`、`@vue/runtime-dom` 均报告版本 `3.5.43`、`license: MIT`；五份实际 `LICENSE` 均为 1091 字节，SHA256 相同：`1bb85cc9b13b81ef41c81c51866172fc345e0503c86726a6755b796590b70175`。

## 修复与范围

新增固定 Vue runtime notices helper，只读取上述五包的 package 元数据与 `LICENSE` 正文，按正文完全相同分组并原文输出；缺文件、元数据无效或正文为空时明确失败。预览构建在 Vite 清理旧输出前生成 notices，README、manifest、SHA256 与 Vue 专用 `preview:verify` 同步包含并对照当前安装内容逐字复核该文件。通用 ZIP 验包仍检查白名单、清单与完整性，不自动判断任意依赖许可是否齐全。前端源码 Profile 要求交付 helper。范围不自动扩展到新增依赖，也不构成全依赖审计或法律结论；旧 7 文件 Vue 预览须重新构建。

## 复现、根因与影响

- 复现基线：打开上述旧 7 项静态预览，检查归档清单和 `app.js` 的许可注释；可确认归档缺少完整许可正文和 `LICENSE` 文件。此问题影响 Vue 运行时组件的随包许可文本可读性，不代表其它依赖许可已审计。
- 根因：Vue 构建产物原有运行时归属注释，但静态预览文件集没有生成或校验完整的运行组件许可正文，旧归档因此无法随包提供该文本。
- 错误特征：静态包中的 Vue 运行许可正文缺失，由构建/验包校验完整 notices 修复。
