# ERR-20261028-003：构建预览请求缺失 favicon

- 状态：已解决（限独立源码包构建预览的 Edge HTTP 验收）
- 日期：2026-10-28
- 范围：[Issue #138](https://github.com/TgStudio-PM/PM-product-workflow/issues/138)；可选 Vue starter 静态预览构建与独立源码交付

## 现象与复现

旧基线 `5ed9a22` 的源码包解压、安装并启动构建后的 HTTP 预览时，请求 `/favicon.ico` 返回 404。初轮 Chrome 主要检查开发入口；Edge 复验检查的是源码包构建后的静态目录，曾记录一次 favicon 404 和一次 console error，page error 为 0。两次检查的入口不同，现有证据不支持将差异归因于浏览器。

旧基线包审计为 58 项（56 个 manifest 文件及 2 个元数据文件），SHA-256：`5B79A35F3D353E66C5307C05856B7BEF5FBDEAD6693396A5166E6B6E7B4E35B6`。在仓库外全新解压后，Node 20.20.0/npm 10.8.2 下 `npm ci`、预览打包与验包，以及 43 项测试通过。Edge 使用本地 HTTP；2048×1050/DSF 1.25、1280×800/DSF 1、390×844/DSF 1 三视口通过蓝色布局、筛选重置、详情、query-active、hash-history、未知地址反馈和草稿恢复检查。

## 错误特征、影响与根因状态

错误特征与根因：开发入口 `index.html` 已有空 favicon 声明，构建入口 `build-preview` 生成的 HTML 却缺失对应 link，因此构建预览回退请求 `/favicon.ico`。这是两入口产物不一致，不是 Chrome/Edge 差异。影响仅为静态 HTTP 预览中的缺失图标请求与一次控制台错误；不是业务交互错误，也不代表 `file://` 离线或生产行为。

根因已由源码定位。修复已提交于 `44a3f075ec3a61c047d261979fab2e15a6208e74`：构建预览 HTML 精确写入 `<link rel="icon" href="data:,">`；独立验包仅在检查时移除该固定 tag，再扫描其余内容。该处理边界已通过旧包无图标场景，以及非空图标、SVG 图标、data 脚本/样式和远端图标拒绝负例。修复后主线审阅三个源码和测试文件，预览打包与 51 项测试通过。

## 修复验证与验收

机器验证：固定图标声明的唯一例外及其拒绝边界已定向验证，`npm run preview:pack` 和主线审阅通过。独立源码包在仓库外全新解压并隔离安装，Node 20.20.0/npm 10.8.2 下 `npm ci`、预览打包与独立验包通过；51/51 项测试通过，失败 0。复验 ZIP 为 58 项（56 个 manifest 文件及 2 个元数据文件），SHA-256：`FF8F0501B4C24AF528406E3FD0E14C43375F9CE039CB629C472507A48D5C0C23`。

最终 Edge 复验：Edge 155.0.4283.62，候选包 SHA-256 与上述记录一致。2048×1050/DSF 1.25 下桌面交互、带参数路由唯一 active 与 Hash 前进/后退通过；1280×800/DSF 1 下未知 query 不显示角色、表单或 active，实际点击“材料申报”可返回登记页；390×844/DSF 1 下草稿刷新恢复通过，长未知地址无横向溢出。日志中 favicon 请求 0、16 个本地请求均为 HTTP 200、HTTP 4xx 0、console error/warning 0、page error 0、外部 HTTP 请求 0。原始 Edge favicon 404 不再复现，定向交互与机器回归通过，因此本错误仅在独立源码包本地 HTTP 构建预览范围内关闭。

该结果不覆盖 `file://`、零网络离线、Windows 真机 125% 缩放、独立非开发产品经理人测或正式 Release。

## 预防与证据

预防：开发入口与构建入口分别确认 favicon 处理；源码交付复验须在新的唯一临时目录中生成包并隔离安装，记录包哈希、浏览器版本、视口/DSF、图标请求和错误计数。HTTP 验收不得描述为文件离线验收。
