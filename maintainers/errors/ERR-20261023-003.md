# ERR-20261023-003：前端源码交付包内的新增页面链接失效

- 状态：已解决
- 日期：2026-10-23
- 范围：虚构 Vue 原型工程的前端源码包和通用交付验包；原 Issue #69，复发记录见 Issue #97

## 复发记录（2026-10-24）

Issue #97 的新页面指南再次引用源码包根目录之外的 `templates/optional/API_HANDOFF.md`。按官方 `frontend-source` Profile 打包复现，返回 `MARKDOWN-02 relative link escapes bundle root: docs/ADD_PAGE.md:19`，退出码 2，未生成 ZIP。`docs/BACKEND_HANDOFF.md` 存在同类包外引用。原问题在 #69 中已解决，但源码包新增文档时没有把链接目标纳入交付清单审查，因此同类交付故障复发；原错误编号重开。

同时，`page:new` 只创建页面文件和路由注册项，没有创建模块事实文件；指南未清楚说明如何从模块模板建立 `src/modules/<module>/facts/module/`，使页面规则索引无法按预期落到权威事实源。

## 现象与复现

旧前端源码 ZIP 能通过 `package.py --verify`，但包内 `docs/ADD_PAGE.md` 的“新增页面人测卡”链接指向 `docs/ADD_PAGE_TRIAL.md`，该文件没有进入 ZIP。独立审计三类虚构包的 Markdown 相对链接：静态预览 0 处断链、前端源码 1 处断链、后端需求 0 处断链。没有读取或打包真实项目材料。

错误特征：清单和 SHA-256 均有效，接收者解包后仍无法打开被交付文档引用的本地文件。

## 影响与根因

前端源码接收者沿新增页面指南无法打开人测卡，交付材料不完整。直接原因是 `frontend-source.json` 白名单未包含该文件；检查缺口是打包器只对静态预览的 HTML/CSS 做常见本地资源检查，没有审计包内 Markdown 相对链接。

## 尝试及结果

- 固定旧 ZIP 后，旧验包器返回成功；独立包内链接扫描确认一处缺失。
- 在 Profile 的 `include` 和 `required` 中补入人测卡；在生成包及独立验包时检查常见 Markdown 行内相对链接。
- 新版验包器拒绝旧 ZIP，报告 `MARKDOWN-01` 与引用文件行号；重新生成的三类虚构包均通过新版独立验包，独立链接扫描发现 0 处断链。

## 原修复、验证与预防

打包器 30 项测试通过、1 项因本机 Windows 符号链接创建不可用而跳过；治理测试 11 项通过。新增定向测试覆盖有效链接、缺失目标、越出包根目录以及独立验包的断链拒绝。公开内容扫描、仓库 Markdown 链接和差异检查通过；GitHub CI 以关联 PR 为准。

以后改变交付白名单时，应核对包内文档的相对引用，并用独立验包检查实际 ZIP。自动检查仅覆盖常见行内 Markdown 链接，不等同于完整 Markdown 解析、目标浏览器运行或交付对象的产品验收。

原修复证据：[Issue #69](https://github.com/TgStudio-PM/PM-product-workflow/issues/69)、关联 PR 差异与 CI、仓库外本机忽略目录中的三包审计记录。

## 本次复发修复与验证

在 Vue starter 内分发通用模块事实模板和可选 API 对接模板；两个交接指南改为包内相对链接；新增页面指南说明从 `module-template/facts/module/` 建立模块事实文件，并在每个 `RULES.md` 链接到 `../../facts/module/BUSINESS_RULES.md`。`frontend-source` Profile 将两组模板列为必需文件。治理测试检查分发副本与权威模板逐字节一致、Profile 覆盖，并实际调用官方 frontend-source Profile 在临时目录生成 ZIP 和独立验包；该回归运行于 CI 的治理单元测试步骤，不依赖 Node/npm 或浏览器。

- 原始官方 frontend-source 打包命令：通过，`PACKAGE-OK archive built and integrity verified`。
- 独立验包：通过，`VERIFY-OK archive integrity verified`。
- `python -m unittest maintainers.tests.test_governance_checks`：14 项通过；新增官方源码包生成及独立验包测试使用系统临时目录，不写入仓库。
- `python maintainers/scripts/check_markdown_links.py .`：通过。
- `python maintainers/scripts/check_public_content.py --root .`：通过。
- ZIP 检查：53 个条目、19 个 Markdown 文件，必需文档和模板均在包内；SHA-256 `b4640fbc014efc99ec65bb5969fafaa9721763f4ca8053d3df9ae015a5ddc05e`。

以上解决原始复现和包内相对链接审计问题。该验证没有运行浏览器或接收方产品验收，不代表页面 `file://` 运行和业务需求验收。
