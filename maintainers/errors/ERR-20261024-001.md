# ERR-20261024-001：本地 CSS 栅格图片被离线包审计误拒

- 状态：已解决
- 日期：2026-10-24
- 范围：Tg Studio Vue 原型工程的离线预览 CSS 资源审计；Issue #75

## 现象与复现

在隔离副本将本地 PNG 放入 `src/assets/pixel.png`，并在 `src/style.css` 添加 `background-image:url("./assets/pixel.png")`。运行 `node scripts/build-preview.mjs` 成功；Vite 将本地图像内嵌为 `url(data:image/png;base64,...)`，但随后 `node scripts/verify-preview.mjs` 以“样式表包含外部或非本地 URL”退出。复现仅使用忽略目录中的测试资产，没有读取真实项目资料。

错误特征：离线构建成功，生成的 CSS 使用 Vite 内嵌本地图片数据 URI，验包器却把所有 CSS `data:` URL 一概视为非本地引用。

## 影响与根因

原型页面可以在开发模式使用本地 CSS 图片，但含该图片的静态预览包无法通过验包，阻断离线交付。直接根因是 verifier 对 CSS `url(data:...)` 使用统一拒绝规则，没有区分内嵌栅格图片和可加载外部/活动内容。

## 尝试及结果

- 在隔离副本使用 Vite 构建本地 SVG 和 PNG 背景：构建均成功，旧 verifier 均拒绝内嵌结果。
- 锁定安全支持范围为 PNG、JPEG、GIF、WebP、AVIF 的 base64 数据 URI；不放宽 SVG、非图片数据 URI 或远程资源规则。

## 最终修复、验证与预防

Verifier 现在校验受支持 MIME、canonical base64 和对应文件签名，再仅在资源扫描副本中替换已验证的图片数据 URI；原始 `styles.css` 仍纳入 ZIP 清单及 SHA-256。测试在隔离副本构建本地 PNG 并通过验包，核对包内白名单和 CSS 摘要；负向测试覆盖 SVG、非图片 URI、非法 base64、MIME 与签名不匹配以及远程 URL，且先更新 CSS 摘要以避免仅由哈希错误触发拒绝。

`npm run test:preview-verify` 的 12 项测试、`npm run typecheck`、`npm run preview:pack`、公开内容扫描、Markdown 链接及 `git diff --check` 均通过。隔离副本中的原始 PNG 复现已重新构建并通过验包；合并后才进入稳定基线。当前浏览器工具的 URL 策略拒绝打开本地 `file://`，因此图片显示与浏览器网络请求尚未验收，不能用静态审计替代。若原始复现再次出现，沿用本编号重开。

预防规则：扩展 CSS 内嵌资源支持时，必须明确限定 MIME 和内容格式，在隔离副本覆盖允许与拒绝场景，并确认包内白名单和摘要仍覆盖最终构建产物。静态扫描通过不替代目标浏览器验收。

证据：[Issue #75](https://github.com/TgStudio-PM/PM-product-workflow/issues/75)、本 PR 定向测试与隔离复现。
