# ERR-20261026-006：Vue 离线预览漏验 CSS 本地资源

- 状态：已解决（静态包结构审计范围；目标浏览器未作本轮复验）
- 日期：2026-10-26
- 范围：Issue #125；可选 Vue starter 的 `preview:verify` 静态包审计

## 现象与复现

在完全虚构的隔离副本中，原始预览包验包返回 0。向 `styles.css` 添加 `.broken{background:url(./missing.png)}` 并正确重算 `SHA256SUMS` 中该文件摘要后，验包仍返回 0、报告通过。该文件不在包内。复现只检查静态文件，不运行浏览器或访问网络。

首次隔离副本缺少 TypeScript 依赖，验包因模块解析失败而退出；补上指向已有本地依赖目录的隔离 junction 后，同一副本的原包与篡改包均正常运行，确认资源漏验结论不来自环境错误。

错误特征：CSS 显式引用不存在的本地资源，且摘要与内容一致时，结构验包仍报告成功。

## 影响与根因状态

根因已定位：当前 Vue 预览验包器只用模式检查 CSS 中的 HTTP/data URL 特征，不解析普通相对 `url(...)` 或 `@import` 的目标；哈希校验只能发现内容被改动，不能证明内容引用的资源存在。该问题只影响可选 Vue starter 的静态包审计，不表示已有真实交付发生过缺资源事故，也不证明浏览器运行状态。

## 尝试及结果

1. 用隔离虚构包固定原始反例，并排除副本依赖缺失的环境因素。
2. 在原有单文件 CSS 预览范围内检查 `url(...)` 是否为包内相对普通文件；`@import` 被明确拒绝，避免引用未包含的样式文件。保留本地片段引用。
3. 对原始缺失资源、缺失导入、远程/绝对/越界资源和正常预览包执行隔离定向回归。

## 修复、验证与预防

原始缺失资源反例在更新摘要后被拒绝；同组新增测试覆盖缺失 `@import`、远程/绝对/越界 URL 和片段引用。`npm run test:preview-verify`：21 项通过；`npm run preview:pack`（先运行 Vue 类型检查，再构建并验包）通过；`git diff --check` 通过。GitHub Linux CI 结论另见关联 PR，不能由本地结果预先代替。

预防要求：预览包验包需在摘要一致后仍检查明确声明的本地资源；同时验证缺失、越界、远程/绝对引用以及正常预览包，区分静态结构检查与目标浏览器离线验收。

证据：[Issue #125](https://github.com/TgStudio-PM/PM-product-workflow/issues/125)、`starters/vue-prototype/scripts/verify-preview.mjs`、虚构隔离复现。
