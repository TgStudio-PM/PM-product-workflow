# ERR-20261024-008：预览验包测试将合法页面数量固定为两页

- 状态：已解决
- 日期：2026-10-24
- 范围：Tg Studio Vue 原型工程模板的离线预览验证测试；Issue #105

## 现象与复现

在隔离的 Vue starter 副本中运行 `npm run page:new -- demo-help guide "演示帮助"` 新增第三页后，`npm run preview:pack` 与 `npm run preview:verify` 均通过，但 `npm run test:preview-verify` 的 13 项中 2 项失败。失败断言位于 `tests/verify-preview.test.mjs:104-109` 和 `:124-127`，将预览清单和 manifest 固定为原始两页。

本次仅为完全虚构的教学页面，不涉及真实项目资料。原始复现和环境记录见本机忽略目录 `.codex-local/trials/blank-pm-20261024/REPORT.md`；该目录不提交。

## 影响与根因

验证套件将仍合法的新增页面当作错误，导致新增页面后的回归测试失败，阻碍交付验收。根因是两项测试把原始页面数量及完整 `PAGES.md` 文本固定写成两页，而未对照基线验证语义是否保持、单页变化是否局限于目标页面。

## 尝试及结果

- 复现报告显示页面注册、构建和独立验包成功，失败仅发生在两个固定两页的测试断言。
- 尚未修改生产构建或验包脚本；根因限定在测试断言。

## 修复、验证与预防

字段重排测试改为对照构建前的 manifest 和清单基线；特殊标题测试仅改变目标路由的 manifest 标题，并以手写转义行检查 Markdown 输出，保留其余基线页面。新增隔离回归从基线页面路由中选择一个未占用路径（以 `/demo-help/guide` 为首选，冲突时递增后缀），再运行构建和独立验包，并核对 manifest 与页面清单。

- 基线 `npm run preview:pack`：通过；类型检查、构建及静态验包均通过。
- `npm run test:preview-verify`：14 项通过。
- 第三页定向隔离测试：1 项通过（12 项因筛选条件跳过）；测试自身建立并清理临时副本。
- 在复现空白项目的新隔离副本中保留已有 `/demo-help/guide`，先运行 `npm run preview:pack`，再运行完整 `npm run test:preview-verify`：14 项通过；附加页回归自动选择 `/demo-help/guide-1`，未与已有页面冲突。
- `npm run test:page-new`：8 项通过。
- `npm run typecheck`：通过。
- 公开内容扫描、Markdown 链接检查、差异检查：通过。

预防规则：测试以基线比较未改变的页面集合，对指定字段的变化单独检查；新增页面要有独立正向回归。测试只验证构建产物与清单，不代表浏览器 `file://` 或产品验收。

证据：[Issue #105](https://github.com/TgStudio-PM/PM-product-workflow/issues/105)、原始本机忽略目录复现报告 `.codex-local/trials/blank-pm-20261024/REPORT.md`、新隔离副本 `.codex-local/trials/preview-tests-dynamic-pages-20261024/` 中的构建和测试输出。原复现目录及报告未改写。
