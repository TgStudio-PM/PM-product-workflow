# ERR-20261026-007：原生虚构案例误锁定无效提交记录

- 状态：已解决（Node VM 与静态交付结构验证；本轮目标浏览器未复验）
- 日期：2026-10-26
- 范围：Issue #127；原生材料申报教学案例的浏览器本地记录恢复

## 现象与复现

使用原创虚构的 DOM 与浏览器存储桩运行仓库当前 `app.js`：记录为 `{description:"",materials:[],status:"已提交"}` 时，页面恢复为 `submitted`，申请说明 `disabled=true`，两项必备材料均未选。该结果与外部报告的 DOM 模拟线索一致；本仓库复现实际运行了当前脚本，但不是目标浏览器验收。

错误特征：本地记录只有“已提交”标记、缺必填说明或必备材料，页面仍显示提交成功并锁定表单。

## 影响与根因状态

根因已定位：`readState()` 只按存储中的状态字符串还原“已提交”，`restoreDraft()` 随后直接锁定；恢复时没有重新检查 BR-002、BR-003 与 BR-005 的前提。仅涉及完全虚构的静态教学案例和浏览器本地状态，不涉及真实办件、服务端权限或生产数据。

## 尝试及结果

1. 对照案例事实规则和可选 Vue 案例的异常恢复边界，固定最小虚构反例。
2. 原生页面恢复时重新检查说明与必备材料；无效记录保留可用字段、降为草稿，尝试更正存储并如实提示写入结果。
3. 定向测试覆盖说明为空、缺任一必备材料、有效已提交记录、更正写入失败和再次加载；正常提交条件、存储键及材料范围未变。
