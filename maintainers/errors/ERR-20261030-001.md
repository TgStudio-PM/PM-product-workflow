# ERR-20261030-001：独立验包接受 Windows 路径别名冲突

- 状态：已解决（本记录覆盖的路径冲突与包结构检查范围）
- 日期：2026-10-30
- 范围：[Issue #160](https://github.com/TgStudio-PM/PM-product-workflow/issues/160)，`pm-prototype-packager` ZIP 生成与独立验包

## 现象与影响

两份完整虚构 ZIP 均有匹配 manifest 与 `SHA256SUMS`，修复前独立验包返回 `VERIFY-OK`：`trailing-dot-alias.zip` 含 `notes/readme` 与 `notes/readme.`，`file-directory-prefix.zip` 含文件 `slot` 与文件 `slot/child.txt`。前者在常规 Windows 路径处理中归并为同名路径；后者要求同一路径组件同时为文件和目录。接收方无法保真保存归档内容。

命名限制依据 [Microsoft 文件与目录命名规则](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file)，不以 ZIP 哈希有效代替目标系统路径兼容性。

## 根因与修复

`verify()` 原仅按完整 ZIP 路径执行 `casefold()` 查重，没有检查路径组件尾部 ASCII 空格/句点，也未检查文件路径是否为另一条路径的父级。按已锁定最小方案：共享相对路径校验拒绝尾部 ASCII 空格/句点；共享文件树检查拒绝大小写折叠后的文件/父级冲突，生成端覆盖生成元数据，独立验包覆盖完整归档清单。旧歧义包应修正源路径后重新生成 ZIP 与清单。

## 验证与证据

原始修前复现包 SHA256：`trailing-dot-alias.zip` 为 `74e751d19ed16c9cc9e8b84e65f38540ab38638e1e5189d668669ba65ee7b455`；`file-directory-prefix.zip` 为 `fa549f183bac363a621a8ffa158f2e9f0ce94915af6e7761433262946ece2f6c`。两包均在隔离 Temp 目录构造，仅含虚构普通字节，未解压。修复后 CLI 均拒绝（尾部路径返回 `PROFILE-01`，文件/父级冲突返回 `VERIFY-01`），原文件 SHA256 未变。定向用例以完整重签 manifest 与摘要覆盖叶/中间组件尾部空格和句点、两顺序与大小写父级冲突、README 元数据前缀、失败不覆盖及普通路径兼容；打包器 53 项中 52 项通过、1 项因当前环境不能创建符号链接而跳过。三个标准 Profile 均重新生成并通过独立验包；Markdown 链接、公开内容扫描和 `git diff --check` 通过。CI 以 PR 最终提交结果为准。
