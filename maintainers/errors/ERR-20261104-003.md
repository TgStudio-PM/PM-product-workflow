## 现象与复现

在非 Git 目录分别运行 Markdown 链接检查和公开内容检查，两者均以 exit 2 失败，只输出 `[CHECK_ERROR] CalledProcessError`，使用者无法判断下一步。

## 影响与根因

维护者缺少可操作的 checkout、root path 或 base ref 排查提示。根因是 Git 子进程通用异常处理只打印异常类型；本次问题是诊断信息不足，不是将失败误报为扫描成功。
