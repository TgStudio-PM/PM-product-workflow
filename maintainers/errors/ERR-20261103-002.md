# ERR-20261103-002：Vue starter 首页链接未跟随默认入口

- 状态：已解决（限本轮 HTTP 首页返回；`file://` 浏览器验收受阻）
- 日期：2026-11-03
- 范围：Issue #174；`starters/vue-prototype` 首页链接

## 现象与复现

路由以 `pageRegistry[0].path` 作为空 Hash 默认入口，但品牌、正常页 breadcrumb 和未找到页 breadcrumb 曾固定链接到 `#/overview`。隔离副本仅将首项 path 改为 `/tg-studio/workbench`，其余 60 个跟踪源文件一致；正式登记未改。基线 HTTP 浏览器复核中，三处入口均转到 `#/overview` 并显示客户端未找到页；静态资源响应为 HTTP 200/304，并非 HTTP 404。错误页中已有页面列表链接可正向返回当前工作台。浏览器版本未核实；`pageError`/`requestFailed` 未采集，不对其计数作结论。

此前两次递归枚举将深路径压成 basename 并误读 `.eslintrc`，手写 AST 预检也与项目实际解析结果不一致；这些是工具/预检问题，不是产品构建结论。主线随后依据 Git 61 文件白名单及既有 AST 解析确认源夹具有效，才取得上述 HTTP 证据。

## 修复与验证

App 从 `pageRegistry[0].path` 读取本地 `homePath`，三处首页链接改为使用该值，品牌 aria-label 改为通用的“Tg Studio 首页”；README 同步说明空 Hash、品牌和首页链接共用登记表第一项。登记源、router、Hash helper 与其他链接未改。

`typecheck`、`preview:pack`（含类型检查、构建、专用审计）均 exit 0。前端源码 ZIP 独立验包通过，62 项中的 59 个源码载荷均与当前源文件逐字节一致，干净解压 `npm ci` 和 `preview:pack` 均 exit 0。源码 ZIP SHA-256 为 `446466d9e9c1de1866df3cd2b5bcad77c40147a153ca6e3e3a7b3448469ddb14`。未为三处可逆链接新增镜像实现的永久测试，最终提交的完整 CI 另行核对。
