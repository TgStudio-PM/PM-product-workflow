# ADR 0007：开放 UI 工作入口，完善迭代与实现反馈

- 状态：已确认
- 日期：2026-11-12
- 关联：[ADR 0005](0005-workflow-only-product.md)、[ADR 0006](0006-requirements-documentation.md)

## 背景

产品负责人确认已有需求到代码落地的项目实践，并要求进一步提炼本机能力、汇总重复工作流、减少影响阅读的重复提示。实践可用于方法改进，独立目标使用者的完整验收仍按宪章单独记录。

## 决定

1. 在既有迭代指南中补充需求到开发实现的对照、评审处置和交付版本反馈，不新增生命周期 Skill、必填台账或演示应用。
2. 新增 `gov-ui-reviewer` 与 `gov-ui-refactor` 的原创可移植入口，共用已公开的 Profile。前者只读，后者落实明确范围的代码调整并保留现有栈、组件和业务行为。它们解决任务发现与执行边界，检查规则不复制两套。
3. 提供不绑定模型的可选执行角色正文；每项工作的动态边界仍使用既有任务包，不发布个人配置或启用任何本机 Agent。
4. 首页聚焦使用价值，删除重复的展示性声明。公开规则仍集中在维护层；实际操作和验收所需的条件继续按证据说明。

## 来源与后果

公开内容从通用工作模式全新编写，不搬运源项目正文、代码、标识或私有规范，也不再分发本机第三方 Skills。新增入口将 Skills 从四个增至六个；沿用已有名称，使用时明确选择公开版本，避免与本机同名版本混用。本次仅扩展 ADR 0005 当期“不新增 Skill”的限制，其余定位不变。

本机盘点和详细实践核对报告单独交付给负责人，不纳入公开 Git 历史。本次格式、链接、定向行为检查和 CI 只证明对应范围，不改变独立产品经理实际试用与正式 Release 的验收状态。
