# 本地维护状态模板

将本模板复制为 `.codex-local/MAINTENANCE_STATE.md`。目标文件只供同一台电脑上的维护会话接力，必须被 Git 忽略。

```text
【当前任务】当前维护目标；无任务时写“当前无未完成任务”
【远端 main】最近核对的远端提交
【工作分支】当前分支；无任务时写“无”
【关联 Issue / PR】编号或“无”
【已完成】已经落地的内容
【已验证】已执行的检查及结果
【未完成】剩余工作
【下一步】下一项可以直接执行的动作
【阻塞或禁止事项】阻塞、边界限制和不能重复的失败方案
```

规则：

- 新窗口仍须重新核对 GitHub 和实际工作树，本文件不能覆盖远端事实。
- 不记录真实项目材料、凭据或需要长期保存的项目决策。
- 创建可审阅 PR 后，仅把必要的技术摘要写入 PR。
- 任务合并后恢复为“当前无未完成任务”。
