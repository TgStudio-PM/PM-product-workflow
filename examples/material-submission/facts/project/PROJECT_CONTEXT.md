# 项目背景

## 定位

- 产品：云岚公共服务站材料申报教学示例，一个完全虚构的静态网页。
- 使用者：学习 Coding Agent 原型事实治理方法的产品经理与开发者。
- 问题：示范业务规则、页面交互和仓库事实如何共同维护，并展示简单表单的完整状态闭环。
- 当前阶段：首轮教学案例，限一个离线申报页面。

## 已确认范围

- 展示固定事项名称、申请说明和三项虚构材料清单。
- 申请说明和三项材料确认均为提交必填项。
- 草稿保存在当前浏览器的本地存储；刷新后恢复。
- 提交成功后表单进入只读状态。
- 使用者可清除本案例保存的演示数据并重新开始。
- 页面及事实文件仅用于演示，不对应真实政务项目、机构、政策或生产流程。

## 范围外

- 真实政策解释、真实机构或人员、真实申报办件。
- 文件上传、网络请求、后端接口、审批流、真实身份核验和访问权限。
- 跨设备同步、云端保存、统计报表或正式交付包。

## 共享约束

- 业务：只使用本目录中原创的虚构术语和材料名称。
- 设计：保持单页、清楚展示当前状态与下一步；无外部 UI 框架。
- 技术：原生 HTML、CSS、JavaScript；可用 `file://` 打开；仅相对本地脚本和样式资源。
- 交付：`index.html` 为入口，案例本身不依赖构建、安装或网络访问。

## 待确认

- 无。本首轮教学范围不定义真实业务政策或办理时限。
