# 新增页面：产品经理操作说明

页面按模块分目录，配置在应用注册表，数据与规则随页面保存。简单页面按以下步骤完成，耗时取决于交互复杂度。

1. 复制 `page-template/` 到 `src/modules/<模块>/pages/<页面>/`。
2. 在 `mock.ts` 写入明显虚构的页面数据；字段或校验变化时同步 `RULES.md`，把未确认内容标成待确认。
3. 在 `Page.vue` 使用模板和 `src/shared/components/` 中的共享组件实现页面。
4. 在 `src/app/page-registry.ts` 增加页面组件、hash 路由、页面标题、菜单名、演示角色和说明。
5. 执行 `npm run typecheck`，启动 `npm run dev` 打开路由，检查页面与交互。
6. 如果页面需要前后端协作，在所属模块 `contracts/` 记录字段结构、样例、校验和未确认接口问题；不要猜 URL 或 HTTP 方法。

## 页面目录约定

```text
src/modules/<模块>/pages/<页面>/
├─ Page.vue       # 页面结构和交互
├─ mock.ts        # 完全虚构且类型稳定的演示数据
└─ RULES.md       # 业务规则及已确认/待确认状态
```

页面专属的类型可放在模块 `contracts/`；复用数据读取/写入规则放在模块 `data/`。先复用共享组件，确认多个页面需要相同能力后再扩展共享层。

## 验收

- 注册表中的路径唯一，并能从页面导航进入。
- 刷新页面后路由仍可使用。
- 页面展示、mock 字段和 RULES 规则一致。
- 表单错误、空数据、确认操作等页面状态经过检查。
- 如产出离线包，运行 `npm run preview:pack` 并按目标浏览器验证。
