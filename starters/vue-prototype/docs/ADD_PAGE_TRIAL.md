# 新增页面人测卡

用这张卡观察一位未参与模板开发的非开发产品经理，在 Coding Agent 辅助下能否独立新增一个简单信息页。每次复做请填写一份副本；不要预填或推断人测结果。只使用虚构内容，不读取或粘贴真实项目资料。

## 开始前

- 在干净副本中操作，并记录 starter 所用分支或提交。
- 参与者应是非开发产品经理，未参与本模板开发；记录其对 Vue、命令行和 Coding Agent 的熟悉程度。
- 使用者可以向 Coding Agent 求助。参与者负责说明页面内容、检查结果并决定是否接受；Agent 执行的工作也计入页面完成的实际经过时间。
- 准备 Node.js 20.19+ 或 22.12+、可用终端和目标浏览器。记录 Node/npm 版本、操作系统、浏览器名称与版本，以及依赖是否已安装。若需 `npm ci`，单独记录其耗时，不计入新增页面时间。
- 使用以下固定虚构任务：新增一个只读“演示帮助”页，展示三条虚构的使用提示；从应用导航可进入，刷新后仍显示该页。不得增加真实接口或身份能力。

## 判定

- **五分钟目标达成**：页面完成总用时不超过 5 分钟，且产品验收中新增页导航、刷新和内容均通过。单次结果只代表这位参与者、这套环境与此次任务。
- **未达成**：页面完成超过 5 分钟，或上述任一项未通过；记录阻碍，不要通过扣除 Agent 等待或人工时间改变结果。
- **机器验证**另行报告；失败不抹去实测用时，但整体验收需标记未通过并说明失败项。
- 一次或多次人测都不能由之前的 Agent 工程演练替代。报告样本数、个体结果和环境，不将样本结论推广为所有产品经理的能力或普遍耗时。

## 可选的 Agent 工程观察

此前另有一次隔离 Agent 工程演练：页面首次完成约 53.9 秒；包含依赖、类型检查和离线预览审计的总时长约 4 分 51.5 秒。该观察不是本卡的人测数据，也不能证明五分钟目标已达成。若后续公开汇总结果，应只写可公开的汇总事实，不公开本机路径、截图或对话。
