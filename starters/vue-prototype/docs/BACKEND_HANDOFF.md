# 后端接口交接说明

此工程没有生产后端，也没有已确认的 API 地址或 HTTP 方法。`src/modules/material-submission/contracts/README.md` 记录虚构材料申报案例可供讨论的数据结构和待确认项。

## 对接评审时请确认

- 接口 URL、HTTP 方法、API 版本、环境和网关约束。
- 认证方式、身份上下文、角色权限和数据范围。
- 查询、暂存、提交、撤回/清除等操作的服务端语义。
- 请求与响应字段、必填/可空、枚举、时间、ID 和版本字段。
- 文件是否由服务端接收；上传接口、格式/大小限制和扫描规则。
- 分页、排序、并发更新、幂等和重复提交行为。
- 业务错误码与字段校验错误结构，哪些错误可重试。
- 持久化、审计和保留策略，以及联调和验收环境。

只有双方确认后才将结论标记为已确认。当前原型中的“暂存”“提交”和“清除”均在浏览器本地执行，不能映射成已存在的后端操作。不要直接从页面名称推断 API。
