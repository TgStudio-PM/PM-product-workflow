# 材料申报模块业务规则

本文件是 Vue starter 中本模块规则正文的唯一来源。以下内容来自仓库公开的完全虚构教学案例，经重新表述用于验证原型结构；不包含真实项目材料。

| ID | 规则 | 状态 | 当前实现 |
| --- | --- | --- | --- |
| BR-001 | 页面使用 Tg Studio 品牌，事项固定显示为“Tg Studio 示例项目材料申报”。 | 已确认（虚构案例） | `pages/apply/mock.ts` 与页面只读事项字段 |
| BR-002 | 申请说明去除首尾空白后必填，最多 500 个字符。 | 已确认（虚构案例） | 提交校验与输入长度限制 |
| BR-003 | “项目背景说明”和“迭代计划摘要”为必备；“页面流程草图”为可选。确认材料只表示已备齐，不上传文件；提交校验只统计两项必备材料。 | 已确认（虚构案例） | 页面 mock、必备材料计数与提交校验 |
| BR-004 | 未提交内容作为草稿保存在当前浏览器，重新打开页面时恢复。 | 已确认（虚构案例） | 模块 `data/` 的浏览器存储适配 |
| BR-005 | 校验通过后状态变为“已提交”，表单只读且不能重复提交。 | 已确认（虚构案例） | 页面提交状态与控件锁定 |
| BR-006 | 确认清除后只删除本案例专用的浏览器存储键，并回到空白草稿。 | 已确认（虚构案例） | `data/browser-storage.ts` 和确认弹窗 |
| BR-007 | 示例不上传文件、不发起网络请求、不生成真实办件。 | 已确认（虚构案例） | 当前页面及离线构建边界 |

“已确认”仅指本仓库虚构案例设定，不表示真实业务确认。
