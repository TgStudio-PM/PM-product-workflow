# 使用者原型项目入口

本入口只服务当前原型项目，不管理 PM-product-workflow 仓库。项目事实默认位于根目录；请按现有目录调整指针。

## 每轮开始

1. 阅读[项目背景](PROJECT_CONTEXT.md)和[模块清单](MODULE_REGISTRY.md)；按实际目录调整这两个指针。
2. 按模块清单选择本轮涉及的模块，只读取该模块的 `CURRENT.md`、本次实际受影响的规则/流程/决策及已有错误记录；按项目实际目录调整路径。
3. 从当前任务或接续材料中的下一步出发，核对实际入口、源码和文件现场；若项目使用 Git，再核对分支与提交，并保留未提交修改。
4. 检查错误记录中的根因、无效方案和回归证据，避免重复已证伪做法。

## 实施与记录

- 分开记录需求事实、当前实现和反馈版本；未知或冲突保持“待确认”，关键业务缺口交由负责人确认。任务明确时可直接执行。
- 只同步本次受影响的事实；将已完成待办移到完成记录，并更新待处理与下一步。小改动简短补记，不机械新建文件。
- 同类错误等价失败两次后停止盲试，依据已有错误记录定位原因。
- 分别报告产品验收和机器验证，并注明未执行项；留下明确的下一步。
- 仅在核对路径和内容后更新本项目的事实文件。

本文件中的模块路径是指针示例；若项目实际目录不同，先确认真实位置并相应调整，勿将推测写成已确认事实。
